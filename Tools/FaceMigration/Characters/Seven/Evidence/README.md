## 证据保留规则

- `max_samples.json` / `lid_max_samples.json`：源对照，重新拟合和判定实现所需。
- `parameters.json`：多个构建器与验证器直接读取，移动必须同步脚本依赖。
- `previous_controls.json` / `before_outputs.json`：添加部位前的回归基准，不能用新的构建报告替代。
- `validation` / `reload` / 初始值、轴向、行程和布局调整报告：证明具体范围，不扩大成当前全功能实时验收。
- 预览刷新前失败快照和刷新后报告：支撑“Rig 曲线与最终动画曲线不同步”的排障，失败记录不是当前失败状态，不能删掉通过记录或隐去未测范围。
- 早期 28 控制复核支撑眉毛掩码与上眼皮修正结论；只读采集脚本固定指向早期资产，不是当前完整 Rig 的验收器。

非面部迁移的旧混合资产审计已移到项目独立资料；这里不再拿其中的 328 节点、7 Float 或身体 Rig 统计描述当前目标。源采样、参数和回归数据保留原始内容。
